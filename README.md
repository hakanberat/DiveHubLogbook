# Dive Hub Logbook

A cross-platform diving logbook application built with .NET MAUI, MVVM, and SQLite.

## Features

- Add dive records
- View diving logbook
- Search dives by dive site, buddy, or notes
- View dive details
- Edit existing dives
- Delete dives
- Dashboard statistics
- Local SQLite database
- Windows and Android support

## Dive Information

Each dive can store:

- Dive number
- Dive date
- Dive site
- Maximum depth
- Bottom time
- Water temperature
- Exposure suit type
- Suit length
- Suit thickness
- Weight
- Dive buddy
- Notes
